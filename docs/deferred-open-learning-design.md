# 暂缓实施：开放式学习设计

状态：仅记录，暂不实施  
记录日期：2026-07-24

## 背景

FanPhysics 已具备题族路径、预测、动画、解析、近似题、真题分轨、学习统计、AI 问答和虚拟实验。后续需要警惕学习流程过度完整后，学生只按系统路线操作，把问题选择、模型建立和理解判断交给页面。

这组构想关注四种长期能力：

1. 用少量底层关系重新组织大量知识的模型压缩力。
2. 在不同领域间迁移结构，并识别类比失效边界的建构力。
3. 在开放问题中判断哪些问题值得继续研究的选择力。
4. 区分事实、推导、假设和证据的自校准能力。

## 候选设计

### 可选学习地图

- L0-L3 题族路径从固定推荐改为可选地图。
- 学生先说明“补基础、同级迁移或提升挑战”的选择理由。
- 系统记录选择依据，不只记录访问了哪道题。

### 模型压缩任务

完成解析后，由学生填写：

- 最少需要哪些物理量。
- 哪条关系控制整个模型。
- 哪些题设条件可以删除。
- 哪个条件改变后结论会失效。

统一表达为：

```text
模型 = 研究对象 + 不变量 + 约束 + 失效边界
```

### 双向映射与反类比

- 现实同构案例先由学生填写原题与现实对象的对应关系。
- 系统映射在提交后显示。
- 增加“现实系统中哪个因素在原题中不存在”的反类比问题。

### 自主选择下一问题

- 完成题目后不立即给出唯一下一题。
- 提供参数反转、模型失效、竞争模型实验等候选问题。
- 学生也可以提出自己的问题，再由系统推荐相关题目。

### AI 分级介入

AI 帮助可分为：

1. 只追问研究对象、依据和边界。
2. 提示需要关注的物理量。
3. 给出主关系但不代入数据。
4. 显示完整解析。

记录学生在哪一级帮助后完成，避免把“看过答案”计为独立掌握。

### 认识论自校准

在预测信心之外记录：

- 当前结论及证据。
- 哪一步是事实，哪一步是推断。
- 使用了哪些未验证假设。
- 什么现象能够推翻当前结论。
- 动画或实验后是否改变判断以及改变原因。

### 开放式虚拟实验

在现有虚拟实验基础上，可进一步允许学生：

- 自主选择测量量和拟合变量。
- 判断异常数据是否舍弃。
- 解释非零截距。
- 区分相关关系与因果支持。
- 设计下一轮实验区分随机误差和系统误差。

## 暂缓原因

- 对当前学生可能过于抽象，会增加页面长度和认知负担。
- 需要真实课堂使用数据才能判断是否改善学习质量。
- 现阶段应先观察题族路径、分轨、误区统计和虚拟实验的实际使用效果。

## 重新启动条件

满足以下任一条件后再考虑原型：

- 学生能够稳定完成现有预测、解析和近似题流程。
- 有明确反馈表明现有路径过度提示或缺少自主探索。
- 能选定一个章节和少量学生进行对照试用。
- 能定义可观测指标，例如独立建模率、提示层级、迁移成功率和高信心错误率。

若重新启动，先在必修二结业测试中选择 1-2 道题试行，不做全题库推广。
